# مراجعة الأمان ونموذج التهديدات — CycleCare (دورتي)

تاريخ المراجعة: 2026-10-17

---

## 1. نموذج التهديدات (Threat Model — STRIDE)

| فئة التهديد | السيناريو المحتمل | ضوابط الحماية المطبّقة في الكود |
|---|---|---|
| **Spoofing (انتحال الهوية)** | سرقة رمز جلسة أو تخمين كلمة مرور المستخدمة أو فتح التطبيق من متطفّل على الهاتف. | تجزئة كلمات المرور ورموز PIN عبر `PBKDF2-HMAC-SHA256` بـ 210,000 دورة وملح عشوائي 128-بت (`app/services/auth.py`)، رموز وصول موقّعة بـ `HMAC-SHA256`، تدوير رموز التحديث (`refresh_token_hash`)، وقفل التطبيق محليًا برمز PIN/بصمة مع وضع التمويه (`Disguise Mode`). |
| **Tampering (التلاعب بالبيانات)** | حقن SQL أو التلاعب بسجلات مستخدمة أخرى أو تعديل مخرجات الـ LLM لتمرير تشخيص طبي أو جرعة دواء. | استعلامات SQL معلّمة بالكامل (`?`) في `app/services/store.py`، فحص ملكية السجل عبر `user_key` المرتبط بالجلسة الموثّقة، وطبقة تحقق صارمة بعد الموديل (`app/services/validator.py` و`app/services/ai_pipeline.py`) ترفض أي استشهاد من خارج `allowed_ids` أو أي رقم غير مدعوم. |
| **Repudiation / Information Disclosure (تسريب البيانات الصحية)** | ظهور تفاصيل الدورة أو الأعراض في إشعارات شاشة القفل، أو تسريب نصوص المحادثة في سجلات الخادم (`audit.jsonl`)، أو إرسال بريد/هاتف للمزوّد السحابي. | قوالب إشعارات محايدة افتراضيًا لا تكشف أي مصطلح صحي حساس (`app/services/notifications.py`)، بصمة ذات اتجاه واحد `SHA-256` لمعرّف المستخدمة في سجل التدقيق دون حفظ نص الرسالة (`request_excerpt=""`)، وتجريد البريد الإلكتروني وأرقام الهواتف (`scrub_pii` و`scrub_conversation_history` في `app/services/prompt_builder.py`) قبل إرسال أي سياق للمزوّد. |
| **Denial of Service (تعطيل الخدمة وحجب الطوارئ)** | استنزاف حصّة الـ API أو تعطّل المزوّد الخارجي أثناء نوبة نزيف غزير أو أزمة نفسية. | فلتر الطوارئ والأزمات النفسية (`app/services/emergency_filter.py`) يعمل حتميًا **قبل** محدد المعدل (`RateLimiter`) وقبل أي استدعاء للمزوّد الخارجي، كما يعمل محرك القواعد المحلي (`/v1/insights` و`/v1/predictions`) بالكامل دون إنترنت أو مفتاح API. |
| **Elevation of Privilege (تجاوز الصلاحيات والمصادر)** | تسلّل مقالات غير مراجَعة (`draft_unreviewed`) إلى إجابات المساعد أو المكتبة التثقيفية. | فرض شرط `status == "approved"` (أو `verified`) مع وجود اسم المراجِعة وتاريخ المراجعة في `app/services/rag.py` و`app/services/library.py`، وإرجاع رد «لا يتوفر مصدر معتمد» عند غياب المصادر دون استدعاء الموديل. |

## 2. ضوابط الخصوصية وحقوق البيانات

1. **الوضع المحلي المجهول والحساب الاختياري:** يعمل التطبيق فورًا بدون حساب، وعند الرغبة في المزامنة تنشئ المستخدمة حسابًا حقيقيًا باسم مستخدمة وكلمة مرور مع نقل سجلاتها المحلية بسلاسة (`POST /v1/auth/register`).
2. **سجل الموافقات الصريحة (`consents`):** تُسجّل موافقة الشروط والخصوصية وموافقة المساعد الذكي في جدول `consents` مع طوابع زمنية (`granted_at` / `revoked_at`)، ويمكن سحبها في أي لحظة (`POST /v1/consents`).
3. **التصدير الكامل وحق المسح الفوري:**
   - تصدير كامل بضغطة واحدة بصيغ `JSON` (`/v1/export/full.json`)، و`CSV` (`/v1/export/cycles.csv`, `/v1/export/symptoms.csv`)، وتقرير الطبيبة `PDF` (`/v1/export/report.pdf`).
   - حذف كامل وفوري لجميع السجلات (`DELETE /v1/data`) بعد تأكيد صريح.
4. **مشاركة الشريك المحدودة والقابلة للإلغاء الفوري:** تقتصر المشاركة على نافذة التوقع القادمة فقط عبر رمز قابل للإلغاء الفوري (`DELETE /v1/partner-share/{id}`) ولا تكشف أبدًا الأعراض أو الملاحظات اليومية أو الأمراض المشخّصة.
